## 重跑指令

查出來的手機行為會是 0 晚。

```powershell
# 0. 確認資料庫在跑（沒有就開 XAMPP 面板按一次 Start，只按一次）
Get-Process -Name mysqld -ErrorAction SilentlyContinue

# 1. 後端一定要帶這個環境變數，否則連到空的 SQLite
cd C:\Users\user\Projects\Sonnap-Project
$env:SONNAP_DB_URL="mysql://root@localhost/sonnap"
.venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000
```

```bash
# 手錶評分（晚數、分段、分布）
python garmin/run_pipeline.py

# AI 夢境數量與來源
python -c "import json,collections;e=json.load(open('ai/data/ai_advice.json',encoding='utf-8'))['entries'];print(len(e),collections.Counter(v['source'] for v in e.values()))"

# 手機行為、遊戲化、攝影機——問跑著的後端，不要讀檔
```
