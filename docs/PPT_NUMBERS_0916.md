## 重跑指令

在 `Sonnap-Project` 目錄。後端要照 CLAUDE.md 那三行啟動（連 MariaDB）。

```bash
# 手錶評分（晚數、分段、分布）
python garmin/run_pipeline.py

# AI 夢境數量與來源
python -c "import json,collections;e=json.load(open('ai/data/ai_advice.json',encoding='utf-8'))['entries'];print(len(e),collections.Counter(v['source'] for v in e.values()))"

# Python 測試（16 支）
for t in tests/test_*.py; do PYTHONIOENCODING=utf-8 python "$t" >/dev/null 2>&1 && echo "OK $t" || echo "FAIL $t"; done

# Flutter 測試
cd app && flutter test
```

⚠️ `flutter test` 會改到 `app/linux`、`app/macos`、`app/windows` 的自動產生檔，跑完
`git checkout -- app/linux app/macos app/windows` 丟掉。
⚠️ 手機行為、經驗值、攝影機的數字要問**跑著的後端**（`/insights`、`/game`），
不要直接讀 `data/sonnap.db`——那是空的。
