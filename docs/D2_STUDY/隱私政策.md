# Sonnap 隱私政策

> 版本 1．2026-09-06｜適用於課程專題實測期間側載安裝的 Sonnap App
>
> 這份文件與 [知情同意書](知情同意書.md) 第三、四節說的是同一件事，
> 只是寫成給「使用 App 的人」看的版本。**兩份如果有出入，以程式碼為準，
> 並且回頭把兩份都改掉**（同一件事有兩種說法時，讀的人無從判斷哪個是真的）。

## 一句話

**我們收集你每晚最後一次操作手機的時刻，加上你自己取的暱稱。其他都沒有。**

## 收集什麼

| 收集 | 上傳 | 用途 |
|---|---|---|
| 暱稱（自取，不必真名） | ✅ | 畫面上叫你的名字 |
| 使用者代碼（App 自動產生） | ✅ | 分辨這些資料是誰的 |
| 目標就寢時間 | ✅ | 算「比目標晚了幾分鐘」 |
| 每晚最後一次操作手機的時刻 | ✅ | 就是這個研究要看的東西 |
| 各 App 的使用時間 | ❌ **只留在你手機上** | 畫「睡前分心」那張圖 |
| 最前景的 App 名稱（僅開啟阻斷功能時） | ❌ **不上傳** | 決定要不要跳提醒 |

## 不收集什麼

真實姓名、學號、電話、Email、位置、通訊錄、相簿、麥克風、
訊息內容、通知內容、螢幕截圖、廣告識別碼。

**沒有第三方 SDK、沒有分析工具、沒有廣告、沒有崩潰回報服務。**
App 只會連到研究者電腦上的那一個位址，不連任何其他伺服器。

## 存在哪、放多久

- 存在**研究者個人電腦**的資料庫檔案，不是雲端
- 只在同一個 Wi-Fi 底下連得到
- 實測結束後，原始資料只保留到報告完成，之後刪除
- 報告只呈現彙總數字，不含暱稱與逐晚紀錄

## 安全性（誠實說明）

⚠️ **這個系統沒有帳號密碼。** 你的使用者代碼本身就是憑證，
任何拿到它的人都能讀你的資料。這是雛形階段的已知限制，
不是我們忘了做。傳輸走的是區網 HTTP，**沒有加密**。

我們的因應：代碼不顯示在畫面上、不寫進系統紀錄、不出現在報告；
伺服器只在測試期間開著。

如果你不能接受這一點，請不要參加——這完全沒問題。

## 你的權利

**看**、**刪**、**隨時退出**。跟研究者說一聲即可，不需要理由。
刪除是連帶刪光的（資料庫設了連鎖刪除，並有一條驗收測試在守）。

移除 App 就立刻停止收集。

## 這不是醫療服務

App 顯示的分數與建議都不是醫療意見，不能用來診斷或治療任何疾病。
有睡眠困擾請找醫師。
